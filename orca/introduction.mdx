## What is ORCA?

ORCA™ is an AI platform for the teams who stand up and maintain Oracle Fusion Cloud — HCM, Finance, and Supply Chain. It works directly against your environment on the two jobs that consume most of an implementation: getting data into Fusion, and managing configuration across environments.

**Data conversion.** ORCA takes legacy data from any source system into Oracle Fusion — preparing and validating it, generating the HDL and FBDI load files Oracle expects, submitting them, and working the error cycle with you until the load is clean. Every fix it learns is carried into the next cycle, so each pass is faster than the last.

**Configuration Workbench.** ORCA manages Oracle setup across your environments — the migration from one to the next, the drift between them, and a versioned history of both. Pull configuration — value sets, user-defined tables, fast formulas, and other Functional Setup Manager tasks — into a workbook, review and edit it, see what has drifted from its source, and push a targeted set of changes into the next environment as governed inserts and updates.

Everything happens inside your own Oracle security: each read and write is a governed Oracle call made as the connection's user. And when you simply need an answer — who holds a role, what's driving a license count, which workers are scheduled — you can ask ORCA in plain language, from the app or from Claude, where a question can just as easily become a chart or a live dashboard over your governed data.

## How it works, in one line

You set up a **connection** to an Oracle pod and add your **AI key**. Then you either **convert** legacy data through a **project** with **cycles** and **entities**, or use the **Configuration Workbench** to move setup between environments — while **ORCA chat** answers questions along the way.
